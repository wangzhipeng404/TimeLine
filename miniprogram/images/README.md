# 图标文件说明

需要在 `images/` 目录下添加以下图标文件：

## TabBar 图标（建议尺寸 81x81px）

- `tab-home.png` - 首页图标（未选中）
- `tab-home-active.png` - 首页图标（选中）
- `tab-settings.png` - 设置图标（未选中）
- `tab-settings-active.png` - 设置图标（选中）

## 图标获取方式

1. 使用微信开发者工具自带的图标资源
2. 从 iconfont.cn 等图标网站下载
3. 使用在线图标生成工具

## 临时方案

如果暂时没有图标，可以：
1. 在 app.json 中移除 tabBar 配置
2. 或者使用任意 PNG 图片临时替代
